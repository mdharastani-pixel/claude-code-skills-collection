# Receipt-Backed Campaign Copy

Writes ecommerce campaign copy in which every claim is tied to a checkable source from the store's own data, and tests it on three simulated shoppers before handing it over.

## Install

Copy SKILL.md from this folder into ~/.claude/skills/receipt-backed-campaign-copy/ on your machine. Nothing else is needed: one Markdown file, no scripts.

## Ideas and credits

This skill is original text. It merges ideas from:

- [takechanman1228/claude-ecom](https://github.com/takechanman1228/claude-ecom): Keep the numbers apart from how you read them, and frame every finding as 'what is, why it matters, what to do' with vague verbs banned.
- [takechanman1228/claude-persona](https://github.com/takechanman1228/claude-persona): Test a message on a small, varied panel of simulated buyers who each react separately, so objections come out before money is spent.
- [gabelul/slopbuster](https://github.com/gabelul/slopbuster): Sweep for machine-written phrasing twice, because removing the obvious tells can leave flat, voiceless copy.

Licenses of the sources: takechanman1228/claude-persona (MIT), takechanman1228/claude-ecom (MIT), gabelul/slopbuster (MIT).
